The first version of HSC: a classic **Huffman** compressor. It gives common
bytes short codes and rare bytes long codes.

- Shrinks English text to about **50–55%** of its size
- `.hsc` files start with a `HSC` + version header, so other files and future
  versions are rejected cleanly instead of decoding to garbage
- The encoder and decoder always build the identical tree (symbols are sorted
  before tree building)

**Fixed before release:** the decoder could build a different tree from the
encoder when byte counts tied, which garbled some small files. The encoder
was never affected, so every 1.0 file ever made decodes correctly with this
release.

**Limits:** loads the whole file into memory and stores sizes as 32-bit, so
it handles files up to a few hundred MB. HSC 2.0 removes both limits, and it
can still open 1.0 files.

### Download
| OS | File | How to install |
|---|---|---|
| Windows | `hsc-windows.zip` | Unzip, double-click `install.cmd` |
| macOS | `hsc-macos.zip` | Unzip, run `sh install.sh` |
| Linux | `hsc-linux.tar.gz` | Extract, run `sh install.sh` |
| Any | `hsc.py` | `python3 hsc.py c file` |

Requires Python 3.8+. 1.0 had no installers of its own; these downloads
package it with the same installers as 2.0.
