HSC 2.0 is a new engine: **seven models guess every byte, and only the winner
gets written.** It's built for sensor data such as lidar, IMU logs and
fixed-size records.

| Test file | gzip -9 | xz -9 | HSC 1.0 | **HSC 2.0** |
|---|---|---|---|---|
| Lidar-style records (2.1 MB)* | 51% | 33% | 57% | **28%** |
| Garry's Mod save (234 KB) | | | | **29%** |

\*Synthetic Ouster-style data; real-world benchmarks coming.

### What's new
- **Seven guessing models:** RLE, RECORD, RECORD-TREND, BYTE-TREND, MATCH,
  ORDER-2 and ORDER-1, with an adaptive range coder
- **Auto-detected record size,** with separate statistics for each byte
  position in a record
- **Streaming:** about 10 MB of RAM for any file size, with 64-bit lengths
- **Stores data raw** when it won't compress (video, zip), with 14 bytes of
  overhead
- **`--trace`** shows which model won every byte
- **`hsc --help`**, plus friendly hints for common mistakes
- **Installers** for Windows (right-click Compress/Extract, `.hsc` file type),
  macOS and Linux
- Opens **HSC 1.0** files, including the tie-heavy ones that tripped up the
  original 1.0 decoder

Windows, macOS and Linux machines before this release was published.
